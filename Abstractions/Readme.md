This library contains a shared interface and related data classes to let you write a plugin for [WinampNowPlayingToFile](https://github.com/Aldaviva/WinampNowPlayingToFile).

Your plugin project should depend on this package.

- [Documentation with examples](https://github.com/Aldaviva/WinampNowPlayingToFile/wiki/Plugin-Authoring)
- [Sample plugin source code](https://github.com/Aldaviva/WinampNowPlayingToFile/tree/master/ScreensaverPlugin)
